# UrbaCargo

Aplicación móvil de mensajería urbana sostenible construida con Expo, React Native, TypeScript, Expo Router y NativeWind.

## Ejecutar

```bash
npm install
npx expo start
```

## Rutas implementadas

- `app/login.tsx`: inicio de sesión.
- `app/(tabs)/index.tsx`: dashboard.
- `app/nuevo-envio.tsx`: creación de envío.
- `app/seguimiento/[id].tsx`: seguimiento en tiempo real simulado.
- `app/(tabs)/envios.tsx`: historial de envíos.
- `app/resumen-envio.tsx`: comprobante y calificación.
